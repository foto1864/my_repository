# Instructions on how to use the program
You are going to have to insert a .txt file in this directory:
birthday_notifications_new/ that you are going to need to specifically
name as "birthdays.txt". Inside there, you are going to need to type in
the birthdays of the people you know and love.

# Format of birthdays.txt
In order for the program to work properly, the .txt file that you insert
in the directory must be of specific format. You are going to write the
birthdays and names of the people you include in the following format:
DD MM YYYY Name Name \n, starting from the second line of the .txt file.
In the first line of the .txt you are kinfly requested to mention how
many people you have included in the file.

# Example of a valid birthdays.txt
3
11 11 2011 John Appleseed
12 10 2001 Bryan Appleseed
10 09 2003 Gordon Appleseed

# Execution of the file
Once you have completed the previous step, including a birthdays.txt in
the correct format, simply open the terminal in the directory:
birthday_notifications_new/ and type: 
make [ENTER]
make run [ENTER]
Then the program should run with no worries. Thank you for using our program!!
